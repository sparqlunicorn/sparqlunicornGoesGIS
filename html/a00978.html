143# What's the difference between PublicID and BaseURI?
144# The BaseURI is a part of Turtle and SPARQL spec, it is used to resolve relative URIs.
145# The BaseURI usually ends with a filename (eg, https://example.com/validators/shapes)
146# BaseURI can sometimes end with a / if URIs are relative to a directory.
147# You will rarely see a BaseURI with a # on the end.
148# The PublicID is a concept inherited from the XML specificaion
149# RDFLib uses PublicID for the Identifier of a Graph. It is the canonical name of the graph,
150# regardless of its hosted location. It is also used to refer to a Named Graph in a Dataset
151# and this is the name referenced in the owl:imports [ schema:name <publicID> ] statement.
152# PublicID is not found in the Turtle file, it is known outside the file only.
153# PublicID can end with a / or a # if you want consistency with the graph's base prefix.
